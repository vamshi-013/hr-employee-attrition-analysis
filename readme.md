# HR Employee Attrition Analysis

This project analyzes employee attrition using an HR dataset containing information about 1,470 employees.

I used Python and Pandas for data analysis, Matplotlib for visualizations, and SQLite with SQL to explore employee attrition from different perspectives.

## What I Analyzed

- Overall employee attrition
- Attrition by department
- Attrition by overtime
- Attrition by job role
- Monthly income comparison
- Job satisfaction and attrition

## Dataset

The dataset contains:

- 1,470 employee records
- 35 columns
- No missing values

Some important columns used in the analysis are:

- Age
- Attrition
- Department
- JobRole
- MonthlyIncome
- OverTime
- JobSatisfaction
- WorkLifeBalance
- YearsAtCompany

## Tools Used

- Python
